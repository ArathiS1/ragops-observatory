# Root-cause attribution benchmark

Generated by `ragops benchmark`. Each case is a healthy RAG call with one failure injected on purpose; the classifier must name the pipeline stage that was broken. Judge: deterministic heuristic judge (no LLM calls), so the numbers are exactly reproducible.

- **Cases:** 365 (309 injected failures + healthy controls)
- **Attribution accuracy:** 89.6%
- **Macro recall across the 7 stages:** 89.9%
- **False-alarm rate on healthy calls:** 1.8%

## How failures are injected

| Stage | Injection |
|---|---|
| knowledge_gap | Questions on topics absent from the corpus, answered confidently |
| stale_knowledge | Context chunk served from document v1 while the registry holds v2 |
| chunking_defect | Question built from the end of chunk *i* and the start of chunk *i+1*; only chunk *i* in context |
| retrieval_miss | Every chunk of the relevant document removed from the candidates |
| ranking_failure | Relevant chunk in the retriever candidates but not in the prompt |
| context_overload | Relevant chunk buried at position 6 of 10 unrelated chunks |
| generation_failure | Relevant chunk at rank 1, answer corrupted (wrong figure or invented claim) |

Limitations: the corpus is small (18 documents) and synthetic, and failures are injected one at a time. Real systems mix failure types; treat these numbers as a regression baseline for the classifier, not as a claim about every production system.
