# Getting help

- **Questions and ideas:** open a thread in [GitHub Discussions](https://github.com/ArathiS1/ragops-observatory/discussions).
- **Bugs:** open an [issue](https://github.com/ArathiS1/ragops-observatory/issues/new/choose) with your RAGOps version
  (`ragops version`), what you ran and the full error output. Remove API keys and private data first.
- **A wrong diagnosis or score:** use the "Diagnosis report" issue template and include the trace or test case.
- **Security problems:** never in public issues; see [SECURITY.md](SECURITY.md).
- **Documentation:** <https://arathis1.github.io/ragops-observatory/>
