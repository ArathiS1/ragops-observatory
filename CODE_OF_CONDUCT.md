# Code of conduct

RAGOps Observatory is a project for people who build reliable AI systems. Everyone who takes part (in issues, pull
requests, discussions or any other channel) is expected to:

- be respectful and assume good intent, including when you disagree about technical choices;
- give and accept constructive feedback about work, never about people;
- welcome newcomers and explain context they may be missing;
- never harass, insult, threaten or discriminate against anyone, in public or in private;
- not share anyone's private information without their explicit permission.

Maintainers may edit or remove contributions, and block participants, that break these rules.

To report a problem, use GitHub's private "Report content" option or open a private security advisory; reports are
handled confidentially. This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org).
